AURA Vault · stockage objet chiffré

Cet hôte sert l’API S3, pas l’interface web.

L’adresse ${S3_DOMAIN} est l’endpoint de stockage objet. Un navigateur qui ouvre la racine envoie une requête S3 non signée : la réponse XML ci-dessous est la réponse normale de l’API pour cette requête, pas une panne.

Réponse de l’API

<Error>
  <Code>AccessDenied</Code>
  <Message>Access Denied.</Message>
  <Resource>/</Resource>
</Error>
Ouvrir AURA Vault Connexion requise pour gérer les fichiers.

Clients S3

AWS CLI, SDK et applications compatibles S3 : utilisez l’endpoint https://${S3_DOMAIN}. Les requêtes signées sont servies normalement.
